### 1.1 Quick Add на таймлайне

**Зачем:** Ядро манифеста. Двойной клик → название → Enter → задача на месте. 10 секунд.

```
ГОТОВО ✅ (через модалку AddTaskDialog с defaults)

  1. Двойной клик по ячейке таймлайна (TimelineRow)
  2. Открывается AddTaskDialog с предзаполненными полями:
     - Дата = день куда кликнул (getDateFromEvent)
     - Assignee = строка на которую кликнул (rowId)
     - Project = из группировки (если есть)
  3. Пользователь печатает название → Enter → задача создана
  4. Esc / клик вне модалки → отмена

Цель манифеста "10 секунд на задачу" достигнута.

Опциональный апгрейд (не приоритет):
```
