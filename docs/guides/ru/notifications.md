# Уведомления

## Колокольчик

**🔔** в верхней панели собирает то, что касается вас. На телефоне тот же список — в
меню под вашим аватаром, на котором видно число непрочитанных.

| Уведомление приходит, когда… |
|---|
| вам назначили задачу |
| вас упомянули в комментарии через **@** |
| кто-то изменил или удалил вашу задачу |
| ваша выгрузка данных готова или не удалась |

Приглашения в другие пространства — в том же списке, в разделе **Приглашения**, с
кнопками **Принять** и **Отклонить**.

Непрочитанные подсвечены. Щёлкните по уведомлению — откроется задача; открытая задача
отмечает свои уведомления прочитанными. У каждого есть **Отметить как прочитанное** /
**Отметить как непрочитанное** и **Удалить**, а **Удалить все** очищает список.

Чтобы список не шумел, несколько правок одной задачи одним человеком за пару минут
приходят одним уведомлением, и правка целой серии повторов — тоже одним. Напоминаний о
сроках Motio не шлёт: эту работу раз в день делает [утренняя сводка](#утренняя-сводка).

## Push-уведомления

Push приходит, даже когда Motio закрыт.

1. **Настройки аккаунта → Уведомления → Уведомления в браузере**: включите и разрешите
   уведомления, когда браузер спросит.
2. Выберите, о чём сообщать: **Мне назначили задачу**, **Меня упомянули в комментарии**,
   **Изменилась моя задача**.

Щелчок по push открывает задачу. Push настраивается для каждого браузера и устройства
отдельно, так что включите его на каждом компьютере и телефоне, где работаете.

### На iPhone и iPad

iOS присылает push только приложениям на экране «Домой» (iOS 16.4 и новее):

1. Откройте Motio в **Safari**, нажмите **Поделиться**, затем **На экран «Домой»**.
2. Откройте Motio с нового значка и войдите.
3. Включите уведомления там, как описано выше.

После этого на значке видно число непрочитанных уведомлений. На Android push работает в
Chrome как есть; чтобы Motio был отдельным приложением, выберите в меню Chrome
**Установить приложение** или **Добавить на главный экран**.

## Утренняя сводка

Когда вы впервые за день открываете Motio после 9:00, короткая сводка показывает ваши
просроченные задачи, задачи на сегодня и сроки этой недели. В день регистрации её нет.
Выключается в **Настройки аккаунта → Уведомления → Ежедневный дайджест**.

## Новости продукта

**Настройки аккаунта → Уведомления → Новости продукта на почту** — редкие письма о
новом. В каждом письме есть отписка в один клик. Что поменялось в каждой версии, есть и в
самом приложении: щёлкните по номеру версии (например, *v0.10.69*) внизу
**Настроек аккаунта**.

Если, пока Motio открыт, вышла крупная новая версия, появится сообщение **Вышла новая
версия Motio** с кнопкой **Обновить**. Сам Motio страницу не перезагружает, так что
набранное не потеряется. Небольшие обновления приходят без сообщения: при следующем
открытии или обновлении страницы.
