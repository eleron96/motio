# Security

Motio holds teams' working data, so security reports are welcome and read carefully.

## Reporting a vulnerability

Please **do not open a public issue or discussion** for anything security-related.

Report it privately instead:
**[Report a vulnerability](https://github.com/eleron96/motio/security/advisories/new)**
(repository → Security → Report a vulnerability). Only the maintainer sees the report.

It helps to include:

- what is affected — the hosted app at motio.nikog.net, or the code in this repository;
- steps to reproduce, or a proof of concept;
- what someone could gain by exploiting it.

## Ground rules

Please act in good faith: use only your own account and your own workspace, do not
read, change or delete anyone else's data, and do not run denial-of-service or load
tests against motio.nikog.net.

## Supported versions

Only the latest release is supported; fixes ship in the next release.
