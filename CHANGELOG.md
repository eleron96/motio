## [0.7.7] - 2026-05-09
### Changed
- Счётчик вех в строке проекта в сайдбаре теперь показывает **только предстоящие** вехи (статус `current` + `upcoming`), пропуская уже завершённые. Раньше считались все вехи проекта от века до века, что мешало по сайдбару понять «сколько ещё впереди». Подсчёт идёт через тот же `deriveMilestonesWithStatus`, что использует блок «Вехи» внутри карточки — статусы и `statusOverride` уважаются. Если у проекта остались только прошедшие вехи — счётчик скрывается (как и раньше при `count === 0`). На спане счётчика добавлен `title="Предстоящие вехи"` для контекста.

## [0.7.6] - 2026-05-09
### Added
- Модалка предпросмотра задачи (по клику на задачу в карточке проекта) теперь тоже показывает, что задача повторяющаяся: иконка `↻` рядом с названием в заголовке плюс отдельная ячейка «Повтор» в основной сетке с outline-бейджем (тип повтора: «Daily recurring», «Weekly recurring», …) и счётчиком «N в серии · N more / Last in series». Раньше в модалке вообще никаких следов повторения не было — теперь общая инфа едина с рядом задачи в TasksBlock.

## [0.7.5] - 2026-05-09
### Fixed
- В блоке «Задачи» карточки проекта снова отображается индикатор повторяющейся задачи: иконка `↻` слева от названия и Outline-бейдж с типом повтора («Daily recurring», «Weekly recurring», «Monthly recurring», «Every 4 weeks», «Yearly recurring») в ряду метаданных. На hover бейджа title показывает остаток серии («N more» / «Last in series»). До этого репит-задачи в новом TasksBlock визуально не отличались от обычных, хотя `repeatMeta` уже приходило в строки.

## [0.7.4] - 2026-05-08
### Added
- Звёздочка отслеживания и кнопка `⋯` теперь всегда видны в строке проекта в сайдбаре (не нужно наводить мышью). Звёздочка с пустым контуром если проект не отслеживается; клик — становится янтарной и проект уходит наверх.
- В шапке карточки проекта (рядом с кастомным статусом) добавлены те же звёздочка + `⋯` меню. Кебаб содержит «Изменить проект» / «Архивировать» / «Удалить» (для редакторов).

### Changed
- Лента заметок и read-modal теперь корректно сохраняют переносы строк из rich-text редактора. Для строк превью переход на plain text + `white-space: pre-line` — каждый Enter в редакторе превращается в визуальную строку независимо от того, какой тег браузер использовал (`<p>`, `<div>` или `<br>`).
- В сайдбаре строка проекта стала компактнее: команда-владелец, число вех и статус теперь живут в одной нижней строке (раньше каждый был на своей).

## [0.7.3] - 2026-05-08
### Added
- В новом сайдбаре проектов вернулась «звёздочка» — каждый пользователь может добавить проект в свои отслеживаемые. Отслеживаемые проекты автоматически поднимаются наверх списка и помечены янтарной звездой. Toggle живёт в выпадающем меню `⋯` на строке проекта (доступно даже без прав редактирования — это персональная настройка).
- Страница проектов теперь запоминает в браузере: текущую вкладку (Projects/Milestones/Customers), активный проект и заказчика, фильтры по заказчикам и команде-владельцу, переключатель «Активные/Архивные». При следующем заходе всё восстанавливается ровно как оставили.

### Changed
- Лента заметок: показывает до 5 строк текста (было 4), уважает переносы из исходной заметки в коротком превью — параграфы из rich-text редактора преобразуются в строчные `<br>`-разделители только в feed-row, в самой модалке полное оформление сохраняется.
- Закреплённые заметки больше не имеют пунктирной линии снизу — drop-shadow достаточно для визуального разделения.

## [0.7.2] - 2026-05-08
### Changed

## [0.7.1] - 2026-05-08
### Changed

## [0.7.0] - 2026-05-08
### Added
- В блоке «Команда» внешних участников теперь можно редактировать целиком — имя, компанию, роль, плюс уже существовавшие email/телефон/тег. Workspace-участники (Motio) по-прежнему правят только email/телефон/роль/тег здесь — их имя живёт на странице «Участники».
- В блоке «Заказчик» появилась полноценная правка контактов (раньше была только добавление и удаление). Карандаш на каждой строке открывает inline-форму на десктопе или bottom-sheet на мобиле — все 5 полей: имя, должность, тег, email, телефон.
- Закреплённые заметки теперь «прибиты» к верху ленты при скролле (как закреплённая строка в Excel) — пока не открепишь, всегда на виду.

### Changed
- Лента заметок при открытии проекта автоматически прокручивается в самый низ к свежим записям. Юзер скроллит вверх к старым; пока он там — новые записи не «дёргают» его позицию. Если он у низа — лента подъезжает к новым автоматически.
- На десктопе блок «Заметки» ограничен высотой ~5 строк ленты (если заметок меньше — высота меньше). Лишнее скроллится внутри блока, не растягивая страницу.

## [0.6.0] - 2026-05-08
### Added
- Закрепление заметок проекта: каждый редактор может закрепить заметку (Pin) — она всплывает наверх ленты и подсвечивается янтарной полоской слева. Иконка справа от имени автора в строке: один тап и заметка закреплена/откреплена без открытия модалки. То же действие в самой модалке заметки — в выпадающем меню `⋯` справа сверху. Миграция `0088` добавляет поле `project_activity.pinned` с partial-индексом для быстрой сортировки.
- Поиск по заметкам теперь показывает фрагмент текста вокруг найденного слова с подсветкой (`<mark>` янтарного цвета). По краям фрагмента многоточия `…` если заметка длинная.
- Курсор автоматически встаёт в поле ввода заметки при создании на десктопе и при тапе «Редактировать» в любой версии — можно сразу копировать-вставить или печатать.

### Changed
- Лента заметок отсортирована от старых к новым: самые свежие записи теперь снизу. Закреплённые остаются наверху, тоже от старого к новому внутри группы.
- Удаление заметки в десктопной модалке переехало из футера в выпадающее меню `⋯` справа сверху (рядом с Pin) — нижний ряд кнопок остался только с «Закрыть» и «Редактировать», случайно ткнуть в Delete уже не получится.
- При входе в режим редактирования заметки фокус больше не «прилипает» к иконке закрепления; курсор сразу попадает в редактор текста.

## [0.5.0] - 2026-05-08
### Added
- Полный новый интерфейс карточки проекта на десктопе и мобиле — под флагами `VITE_FEATURE_PROJECT_CARD` (десктоп) и `VITE_FEATURE_PROJECT_CARD_MOBILE` (мобила, требует первый флаг). Карточка собирает в одном экране: Заказчик с контактами и тегами; Команда (Motio + внешние участники, аватарки, теги, группировка); Вехи с timeline, прошлым/будущим и быстрым добавлением; Заметки (бывшая «Активность») с rich-text редактором, картинками, поиском и переходом к дате; Задачи проекта.
- В сайдбаре проектов добавлены: переключатель Projects | Milestones | Customers (на мобиле тоже единый), фильтр по команде-владельцу, фильтр по заказчикам с группировкой, переключатель активные / архивные.
- В шапке карточки — редактируемый кастомный статус проекта (chip с inline-формой на десктопе и bottom-sheet на мобиле).
- Авто-добавление участников группы при назначении команды-владельца на проект (идемпотентно, удалять можно по одному).
- Все мобильные edit-флоу через bottom-sheets, поднимающиеся над on-screen клавиатурой через Visual Viewport API.
- Миграции 0085–0087: GRANT-ы для новых таблиц, теги/external для project_members, customer_contacts.tag, projects.status.

### Changed
- Mutation-обработчики (контакты, участники, заметки, статус) возвращают `Promise<boolean>` — формы остаются открытыми с черновиком при ошибке вместо «silent success».
- На мобиле верхний MobilePillSubnav убран; переключатель режимов теперь только в боковой панели.
- Десктопный popup контактов получил viewport-clamp и flip; добавлены `aria-modal` и фокус-trap.

### Fixed
- Status-chip больше не теряет черновик при live-sync обновлении проекта во время правки.
- `loadWorkspaceData` не запрашивает таблицы project-card когда фича выключена — нулевая стоимость в prod до включения флага.
- Mobile add-team picker теперь исключает уже добавленных участников.
