# Keyboard shortcuts

On a Mac use **⌘**, on Windows and Linux **Ctrl**. Shortcuts work in any keyboard layout.

## Timeline

| Keys | Does |
|---|---|
| **⌘K** or **/** | search tasks and subtasks |
| **↓** / **↑** | next / previous match in the search |
| **Enter** | open the selected match |
| **Esc** | close the search |
| **⌘Z** | undo the last move, resize, status, priority or project change, or deletion (outside text fields) |

## Mouse on the timeline

| Action | Does |
|---|---|
| **Double-click** an empty spot in a row | new task for that person (or project) and day |
| **Right-click** a day in a row | **Create task** |
| **Click** a bar | open the task |
| **Right-click** a bar | status, priority, project, duplicate, delete |
| **Drag** a bar / its edge | move it / change its length |
| **Double-click** a day in the **Milestones** row | new milestone |
| **Double-click** or **right-click** a date in the header | **Create milestone** |

## In a task

| Keys | Does |
|---|---|
| **Enter** | add the subtask you are typing |
| **Shift+Enter** | new line inside a subtask |
| **Esc** | drop the subtask you are typing; otherwise close the card |
| **@** | mention someone in a comment |
| **⌘Enter** | send the comment |

## Pictures

| Keys | Does |
|---|---|
| **+** / **−** | zoom in / out |
| **0** | back to the original size |
| **Esc** | close |

Gestures on a phone are in [Motio on a phone](./phone.md#gestures-on-the-timeline).
