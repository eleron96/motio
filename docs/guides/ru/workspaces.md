# Пространство и роли

Пространство хранит план одной команды: её людей, проекты, задачи и настройки. Можно
состоять в пяти пространствах. Переключаться между ними и создавать новые — через меню
на названии пространства слева вверху; новое пространство сначала спросит, чем
занимается команда, как и [первое](./getting-started.md#первое-пространство).

## Роли

| | Просмотр | Редактор | Администратор |
|---|:-:|:-:|:-:|
| Видеть весь план, проекты, дашборды | ✓ | ✓ | ✓ |
| Отмечать свои выходные | ✓ | ✓ | ✓ |
| Создавать, менять и переносить задачи; комментировать | | ✓ | ✓ |
| Менять проекты, клиентов, вехи, дашборды | | ✓ | ✓ |
| Менять статусы, типы задач и теги | | ✓ | ✓ |
| Отмечать выходные за других | | | ✓ |
| Приглашать людей, менять роли, группы и доступ | | | ✓ |
| Переименовать пространство, задать праздники, включить тепловую карту | | | ✓ |
| Удалить пространство | | | ✓ |

**Владелец** — тот, кто создал пространство или получил его, — администратор, который
ещё может передать пространство другому.

## Как попасть в пространство

Вас приглашают по почте. Приглашение ждёт в самом Motio, а не только в письме: войдите
**с адресом, на который пришло приглашение**, и оно будет в
[уведомлениях](./notifications.md) в разделе **Приглашения** — нажмите **Принять**, и вы в
пространстве. Если вам прислали ссылку, откройте её и войдите. Принять приглашение может
только тот адрес, на который оно отправлено.

## Настройки пространства

**⚙** рядом с названием пространства открывает настройки. Открыть их может каждый; что
можно поменять — зависит от [роли](#роли).

### Общие

- **Название рабочего пространства.**
- **Календарь праздников** — страна, чьи праздники заштрихованы на таймлайне и
  учитываются тепловой картой, и, если нужно, **Регион** со своими праздниками.
- **Нерабочие дни для всех** (если ваш сервер это разрешает) — закрытие компании или
  общий отпуск: название, первый и последний день. Эти дни выглядят как праздники на
  таймлайне, в календаре и на тепловой карте; личные отсутствия не меняются.
  Администраторы их добавляют, меняют и удаляют.

### Отображение

- **Примеры** — **Убрать примеры** удаляет проекты, людей и задачи-примеры, с которыми
  пространство создавалось.
- **Показывать без назначения** — строка для задач без исполнителя. Это ваша личная
  настройка вида.
- **Тепловая карта загрузки** (*экспериментальная*) — включает
  [тепловую карту](./dashboard.md#тепловая-карта-загрузки) для всех, с необязательным
  **Полным рабочим днём**, который считается за 100%.
- **Плотность таймлайна** (если ваш сервер это разрешает) — **Обычная**, **Маленькие
  фото** (маленькое фото рядом с именем, строки не выше своих задач) или **Компактная**
  (маленькие фото и задачи в одну строку, на экране примерно вдвое больше людей).
  Действует для всех в пространстве на компьютере; на телефоне вид обычный.

### Участники и доступ

**Пригласить:** введите почту, выберите роль (и, если хотите, группу) и нажмите
**Отправить приглашение**. Motio скажет, что произошло:

- **Приглашение отправлено** — человеку придёт письмо со ссылкой, а приглашение ещё и
  ждёт в его уведомлениях.
- **Приглашение создано** — письмо не ушло (например, на сервере не настроена почта);
  человек увидит приглашение, когда войдёт с этим адресом.

У каждого ожидающего приглашения в **Отправленных приглашениях** есть
**Скопировать ссылку** — чтобы отправить её в свой мессенджер или почту — и **Отозвать**.

**Участники** — на вкладках ниже:

- **Активен** — поменять роль или группу; **Отключить участника** выключает доступ, но
  сохраняет задачи и историю; **Удалить** убирает человека из пространства.
- **Отключен** — те, у кого доступ выключен; **Включить участника** возвращает доступ.
- **История** — кто и когда менял роли, группы и доступ.
- **Цвета** — цвета всех людей. Свой может поменять каждый, чужой — администратор.

### Процесс

Собственные списки пространства:

- **Статусы** — у каждого название и, если нужно, эмодзи, который виден на полоске
  задачи. Статусы, которые означают «работа закончена», отметьте как **Финальный**, а
  один — как отменённый.
- **Типы задач** — встреча, проверка, комплект чертежей… всё, что ваша команда различает.
- **Теги** — свободные метки для фильтров.

### Шаблон

- **Добавить из шаблона** — добавляет статусы, типы задач и теги отраслевого шаблона,
  которых в пространстве нет. Ничего не удаляется, примеры не добавляются.
- **Сохранить как свой набор** — сохраняет статусы, типы и теги этого пространства как
  ваш шаблон; он предлагается как **Свой набор** при создании пространства.

### API

Только для администраторов и только если на вашем сервере это включено. Здесь доступ к
пространству получает другая программа:

- **Создать токен** — ключ для одной программы. Выберите, что он может: **Чтение
  пространства** (люди, проекты, задачи, вехи и отсутствия — для отчётов) и/или **Импорт
  отсутствий** (из учёта времени или HR-системы). Токен показывается один раз: скопируйте
  его сразу. Корзина рядом с токеном отзывает его, и программа сразу теряет доступ.
- **ИИ-ассистенты** — ассистент с поддержкой MCP может читать пространство и отвечать на
  вопросы вроде «кто свободен на следующей неделе?». Дайте ему адрес, показанный здесь, и
  токен с правом чтения. Изменить он ничего не может.

Тот, у кого есть токен, читает всё пространство, какой бы ни была его собственная роль:
делайте по токену на программу и отзывайте, когда он больше не нужен. Подробности для
того, кто настраивает: [API](https://github.com/eleron96/motio/blob/main/docs/api.md) и
[MCP-сервер](https://github.com/eleron96/motio/blob/main/docs/mcp.md).

### Опасная зона

- **Передать владение** (только владелец) — владельцем становится другой участник, вы
  остаётесь администратором.
- **Удалить рабочее пространство** (администраторы) — навсегда, с подтверждением
  названием пространства.

## Как покинуть пространство

Администратор уходит кнопкой **Покинуть** рядом со своим именем в **Участники и доступ**;
владелец сначала передаёт владение. Если вы редактор или у вас роль «Просмотр» и такой
кнопки нет — попросите администратора удалить вас. Ваши задачи в любом случае остаются и
снова привяжутся к вам, если вас пригласят обратно.
