# Почта

Motio работает и без почты. Настроенная учётная запись SMTP добавляет письма,
которых люди ждут от веб-приложения, и меняет то, как устроена регистрация.

## Что меняется с почтой

| | Без почты | С почтой |
|---|---|---|
| Приглашения | ждут в уведомлениях Motio; кнопкой **Скопировать ссылку** их можно отправить самому | ещё и письмо со ссылкой |
| Приглашённый без учётной записи | входит или регистрируется, затем принимает приглашение в уведомлениях | получает письмо, чтобы задать пароль |
| Забытый пароль | новый задаёт администратор Keycloak (**Users** → человек → **Credentials**) | ссылка для сброса приходит письмом |
| Регистрация | адрес не подтверждается | адрес подтверждается письмом до первого входа |
| Приветственное письмо после первого входа | — | отправляется |
| Рассылки из админ-консоли | — | отправляются |

Кто что отправляет: Keycloak шлёт приглашения, подтверждения адреса и сбросы
пароля; серверная часть Motio — приветственное письмо и рассылки. Оба пользуются
одной учётной записью.

## Настройка при установке

```bash
infra/scripts/install.sh --domain planner.example.com --email you@example.com \
  --smtp-host smtp.example.com --smtp-port 587 \
  --smtp-user no-reply@example.com --smtp-pass '…' \
  --smtp-from no-reply@example.com
```

Порт `465` работает с TLS с самого начала соединения, любой другой — через
STARTTLS.

## Добавить позже

Задайте в `.env`:

```bash
GOTRUE_SMTP_HOST=smtp.example.com
GOTRUE_SMTP_PORT=587
GOTRUE_SMTP_SECURE=false          # true для порта 465
GOTRUE_SMTP_USER=no-reply@example.com
GOTRUE_SMTP_PASS=…
GOTRUE_SMTP_ADMIN_EMAIL=no-reply@example.com   # адрес отправителя
MAILER_DRY_RUN=0                  # у установок без почты, сделанных старыми версиями, здесь стоит 1
```

Затем выполните `infra/scripts/install.sh up`. Он передаёт Keycloak ту же учётную
запись и включает в realm'е подтверждение адреса. Если `MAILER_DRY_RUN=1` остался,
`install.sh up` и `install.sh status` об этом скажут: почта Keycloak (приглашения,
сбросы) при этом работает, а собственная почта Motio (приветственное письмо,
рассылки, проверка в разделе **Админ-консоль → Система**) — нет.

> [!IMPORTANT]
> Если люди входят через вашего провайдера, настройте доверие к нему **до**
> добавления почты. Иначе Keycloak попросит каждого подтвердить адрес при
> следующем входе. См. [Свой вход](./sign-in.md#подтверждение-почты).

## Проверьте, что работает

Войдите суперадмином и откройте **Админ-консоль → Система**: кнопка **Отправить
тестовое письмо** отправляет короткое сообщение на ваш собственный адрес и
показывает ошибку, если не получилось. У Keycloak своя проверка в его консоли:
realm **timeline** → **Realm settings** → **Email** → **Test connection**.

Отдельная учётная запись для собственных писем Motio (например, маркетинговый
отправитель для рассылок) задаётся параметрами `MAILER_*`; см.
[Configuration](https://github.com/eleron96/motio/blob/main/docs/configuration.md#email-mailer).
