# Требования

## Сервер

| | Минимум | С запасом |
|---|---|---|
| Процессор | 2 vCPU | 4 vCPU |
| Память | 3 ГБ (первая сборка идёт медленно) | 4 ГБ и больше |
| Свободный диск | 15 ГБ | 15 ГБ плюс два объёма вашей базы и загруженных файлов — под бэкапы |
| Система | Linux с Docker | |

У каждого контейнера есть лимит памяти, рассчитанный на сервер с 4 ГБ. При первой
установке веб-приложение собирается прямо на сервере — это самый долгий и
прожорливый шаг.

## Программы

- **Docker** с **Compose версии 2.24 или новее**: `docker compose version`.
- `git`, `python3`, `openssl` и `curl`. В большинстве дистрибутивов они уже есть.
- Права root не нужны. Ставить, обновлять и восстанавливать может пользователь из
  группы `docker`.

## Домен

Имя вроде `planner.example.com` с записью A (или AAAA), указывающей на сервер.
Motio занимает корень одного домена; путь вроде `example.com/motio` не
поддерживается.

## Порты

Зависит от того, как сервер доступен снаружи (подробности — в [Установке](./install.md)):

| Режим | Открыто в интернет | Только локально |
|---|---|---|
| `tls`: Motio сам получает сертификат | 80 и 443 | |
| `proxy`: за вашим обратным прокси | ничего | Caddy на `127.0.0.1:8088` (или в сети Docker вашего прокси) |
| В обоих | | шлюз API и Keycloak на `127.0.0.1:8080` / `8081` — ими пользуется установщик |

## Необязательно

- **Учётная запись SMTP** для почты: письма-приглашения, сброс пароля,
  приветственное письмо. Motio работает и без неё, включая приглашения; см.
  [Почту](./email.md).
- **Ваш провайдер входа** (Authentik, Entra ID, Google Workspace…), если люди
  должны входить под учётными записями компании; см. [Свой вход](./sign-in.md).
- **Бакет S3** для зашифрованных копий ночных бэкапов вне сервера; см.
  [Бэкапы и восстановление](./backups.md).
