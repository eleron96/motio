# Горячие клавиши

На Mac — **⌘**, в Windows и Linux — **Ctrl**. Сочетания работают в любой раскладке.

## Таймлайн

| Клавиши | Что делают |
|---|---|
| **⌘K** или **/** | поиск задач и подзадач |
| **↓** / **↑** | следующее / предыдущее совпадение в поиске |
| **Enter** | открыть выбранное совпадение |
| **Esc** | закрыть поиск |
| **⌘Z** | отменить последний перенос, растягивание, смену статуса, приоритета или проекта, удаление (вне полей ввода) |

## Мышь на таймлайне

| Действие | Что делает |
|---|---|
| **Двойной щелчок** по пустому месту в строке | новая задача на этого человека (или проект) и день |
| **Правый щелчок** по дню в строке | **Создать задачу** |
| **Щелчок** по полоске | открыть задачу |
| **Правый щелчок** по полоске | статус, приоритет, проект, дублировать, удалить |
| **Перетаскивание** полоски / её края | перенести / изменить длину |
| **Двойной щелчок** по дню в строке **Вехи** | новая веха |
| **Двойной** или **правый щелчок** по дате в шапке | **Создать веху** |

## В задаче

| Клавиши | Что делают |
|---|---|
| **Enter** | добавить набранную подзадачу |
| **Shift+Enter** | новая строка внутри подзадачи |
| **Esc** | отказаться от набранной подзадачи; иначе закрыть карточку |
| **@** | упомянуть человека в комментарии |
| **⌘Enter** | отправить комментарий |

## Картинки

| Клавиши | Что делают |
|---|---|
| **+** / **−** | увеличить / уменьшить |
| **0** | исходный размер |
| **Esc** | закрыть |
