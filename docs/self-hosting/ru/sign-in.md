# Свой вход

Motio впускает людей через свой Keycloak. Чтобы они входили под учётными записями,
которые у компании уже есть (Authentik, Microsoft Entra ID, Google Workspace,
любой провайдер OIDC), подключите этого провайдера к Keycloak как внешнего: в
Keycloak это называется *identity brokering*. В самом Motio ничего менять не
нужно.

## Подключение провайдера

1. **У вашего провайдера** создайте приложение OIDC (в Authentik:
   **Applications → Create with provider → OAuth2/OpenID**). Redirect URI:

   ```
   https://<домен>/realms/timeline/broker/<alias>/endpoint
   ```

   `<alias>` — короткое имя, которое вы выбираете сами, например `authentik`.
   Запишите идентификатор клиента, секрет клиента и адрес издателя или discovery
   (в Authentik —
   `https://auth.example.com/application/o/<slug>/.well-known/openid-configuration`).
2. **В Keycloak** (`https://<домен>/admin`): realm **timeline** →
   **Identity providers** → **OpenID Connect v1.0**. Укажите alias из шага 1,
   вставьте адрес discovery, идентификатор клиента и секрет и выберите способ
   аутентификации клиента *Client secret sent as post*.
3. В поле **First login flow** оставьте *first broker login*. Тех, у кого уже есть
   учётная запись Motio с той же почтой, один раз попросят связать их.

На странице входа появится «Войти через &lt;ваш провайдер&gt;». Keycloak остаётся
промежуточным слоем.

## Рекомендуемые настройки

В разделе **Advanced** провайдера в Keycloak:

- **Trust Email** включить, если провайдер сам проверяет адреса почты, как это
  делают корпоративные каталоги. Зачем — в [следующем разделе](#подтверждение-почты).
- **Sync mode: force**, чтобы имена и адреса почты совпадали с провайдером при
  каждом входе.
- По желанию: **Hide on login page** плюс **Login → Identity provider redirector**
  в realm'е (провайдер по умолчанию), чтобы пропускать страницу входа Keycloak и
  сразу вести к вашему провайдеру.

## Подтверждение почты

Без [почты](./email.md) никого никогда не просят подтвердить адрес.

Когда SMTP настроен, `install.sh up` включает в realm'е подтверждение почты. С
этого момента Keycloak просит каждого, кто приходит через вашего провайдера,
подтвердить адрес письмом — если только не доверяет провайдеру:

| Ваш провайдер в Keycloak | Кто входит впервые | Кто уже входил раньше |
|---|---|---|
| Trust Email выключен | просят подтвердить | просят подтвердить |
| Trust Email включён, sync mode *import* | не просят | всё равно просят |
| Trust Email включён, sync mode *force* | не просят | не просят, начиная со следующего входа |

> [!TIP]
> Включите Trust Email и Sync mode: force **до** настройки SMTP. Тех, кого
> спрашивать не нужно, можно отметить и в Keycloak: **Users** → человек →
> **Email verified** включить.

## Группы от вашего провайдера

Группы, которые присылает провайдер, можно отобразить в группы Keycloak (маппер
типа *Advanced Claim to Group* у провайдера, по одному на группу). После этого
Motio может использовать их для двух вещей:

- **Суперадмины** из группы: [Администраторы](./admins.md#или-выдать-через-группу).
- **Пространства** по группам: [Люди и пространства](./people.md#пространства-по-группам).
