# Настройки

Настройки бывают двух видов:

- [Переключатели в админ-консоли](#переключатели-в-админ-консоли): дополнительные
  возможности, которые суперадмин включает в разделе **Админ-консоль → Настройки**
  или из командной строки. Действуют без перезапуска.
- [Параметры в `.env`](#параметры-в-env): адреса, секреты, почта и всё, что нужно
  сервисам при старте.

## Переключатели в админ-консоли

**Админ-консоль → Настройки** показывает, что этот сервер разрешает сверх того,
что Motio умеет из коробки. По умолчанию всё **выключено**, а выключение
переключателя возвращает Motio к работе без него; значения, которые люди успели
ввести, сохраняются и возвращаются при повторном включении. Изменение доходит до
людей при следующем открытии Motio.

| Переключатель | Что разрешает |
|---|---|
| `groups.workspaces` | группы Keycloak помещают людей в пространства ([Люди и пространства](./people.md#пространства-по-группам)) |
| `groups.removeOnLeave` | выход из группы ещё и снимает этот доступ |
| `groups.syncRoles` | переход в другую группу ещё и меняет роль, которую дала группа ([Люди и пространства](./people.md#когда-человек-переходит-в-другую-группу)) |
| `groups.superAdmin` | роль суперадмина может приходить от группы Keycloak ([Администраторы](./admins.md#или-выдать-через-группу)) |
| `timeline.density` | администраторы пространств могут уплотнить таймлайн: фото меньше, строки ниже |
| `heatmap.personCapacity` | администраторы пространств задают каждому человеку долю, 0–100 %, в тепловой карте загрузки |
| `workspaces.closures` | администраторы пространств добавляют нерабочие дни для всех (закрытие компании) |
| `dashboards.transfer` | дашборды можно дублировать, выгружать в файл и загружать |
| `dashboards.calendarPeriods` | виджеты дашборда могут показывать текущую или следующую календарную неделю или месяц |

То же из командной строки:

```bash
infra/scripts/install.sh settings                              # список и откуда взято каждое значение
infra/scripts/install.sh settings set timeline.density on
infra/scripts/install.sh settings reset timeline.density       # вернуть значение по умолчанию (выключено)
```

Значения хранятся в базе, так что они попадают в каждый бэкап и возвращаются при
восстановлении.

Прежние ключи `.env` продолжают работать: `KEYCLOAK_WORKSPACES_FROM_GROUPS`,
`KEYCLOAK_WORKSPACES_FROM_GROUPS_REMOVE` и `KEYCLOAK_SUPER_ADMIN_FROM_GROUPS` со
значением `true` включают свой переключатель и закрепляют его (в консоли видно,
что он включён через `.env`). Значение `false` или пустое оставляет переключатель
на усмотрение консоли.

## Параметры в .env

Все остальные настройки лежат в файле `.env` в каталоге с кодом. После изменения:

```bash
infra/scripts/install.sh up
```

Команда применит изменение везде, где нужно. Параметры, начинающиеся с `VITE_`,
встраиваются в веб-приложение, поэтому `up` пересобирает его — это несколько
минут.

`.env` создаёт установщик и никогда не перезаписывает. Обновление добавляет новые
параметры со значениями по умолчанию и перечисляет их; значения по умолчанию
оставляют всё как было.

### Что вы скорее всего захотите поменять

#### Что видят люди

| Параметр | По умолчанию | |
|---|---|---|
| `VITE_START_PAGE` | `landing` | `app` открывает вход и приложение прямо по вашему адресу, без публичной стартовой страницы |
| `VITE_FEATURE_PUSH` | `true` | push-уведомления в браузере и на телефонах |
| `VITE_FEATURE_KANBAN` | `false` | доска рядом с таймлайном (бета) |
| `VITE_FEATURE_ACCOUNT_DELETION` | `false` | люди могут сами удалить свою учётную запись |
| `VITE_FEATURE_WORKSPACE_API` | `false` | API пространства: другие системы читают пространство и импортируют отсутствия ([API](https://github.com/eleron96/motio/blob/main/docs/ru/api.md)) |
| `VITE_FEATURE_TASK_LIVE_DRAFTS` | `false` | коллеги видят, что человек печатает в задаче |

#### Люди и доступ

| Параметр | По умолчанию | |
|---|---|---|
| `KEYCLOAK_SUPER_ADMIN_FROM_GROUPS` | `false` | `true` включает и закрепляет переключатель `groups.superAdmin` (см. выше) |
| `KEYCLOAK_WORKSPACES_FROM_GROUPS` | `false` | `true` включает и закрепляет `groups.workspaces` |
| `KEYCLOAK_WORKSPACES_FROM_GROUPS_REMOVE` | `false` | `true` включает и закрепляет `groups.removeOnLeave` |

#### Почта, бэкапы, обновления

| Параметр | По умолчанию | |
|---|---|---|
| `GOTRUE_SMTP_*` | пусто | исходящая почта ([Почта](./email.md)) |
| `BACKUP_CRON` | `0 3 * * *` | когда запускается ночной бэкап |
| `BACKUP_RETENTION_COUNT` | `30` | сколько ночных дампов базы хранить |
| `S3_*`, `BACKUP_AGE_RECIPIENT` | пусто | зашифрованные копии бэкапов в бакете S3 ([Бэкапы](./backups.md#копии-вне-сервера)) |
| `MOTIO_UPDATE_CHECK` | `true` | админ-консоль спрашивает у GitHub о новых релизах, не чаще раза в 6 часов, и отмечает раздел «Система», когда релиз вышел; `false` это выключает |

#### Сеть

| Параметр | По умолчанию | |
|---|---|---|
| `MOTIO_HTTP_BIND` | `80` или `127.0.0.1:8088` при `--mode proxy` | где Caddy слушает обычный HTTP |
| `MOTIO_PROXY_NETWORK` | пусто | сеть Docker вашего прокси ([Установка](./install.md#proxy-через-общую-сеть-docker)) |

### Что выключено, пока вы сами не включите

Motio на своём сервере по умолчанию никому ничего не отправляет:

- **Аналитика** (`VITE_PLAUSIBLE_DOMAIN`, `VITE_PLAUSIBLE_SRC`): пусто, поэтому
  никакой скрипт аналитики не загружается. Задайте их, чтобы подключить свой
  Plausible.
- **Отслеживание ошибок** (`VITE_GLITCHTIP_DSN`, `GLITCHTIP_DSN`): пусто. Подойдёт
  любой сервис, совместимый с Sentry.
- **Проверка релизов**: единственный исходящий запрос, см. `MOTIO_UPDATE_CHECK`
  выше.

### Что не стоит менять вручную

- **Пароли и секреты**, созданные установщиком (`POSTGRES_PASSWORD`, `JWT_SECRET`,
  ключи API…): если поменять их только в `.env`, сервисы потеряют связь с
  данными, которые уже используют старые значения.
- **`KEYCLOAK_ADMIN_PASSWORD`**: сначала меняется в Keycloak, потом в `.env`; см.
  [Администраторы](./admins.md#замена-временного-администратора-keycloak).
- **`MOTIO_INSTANCE`**: приставка всех томов с данными. Новое имя запустит пустую
  установку рядом со старой.

Полный список параметров с объяснением каждой переменной — в
[Configuration](https://github.com/eleron96/motio/blob/main/docs/configuration.md).
